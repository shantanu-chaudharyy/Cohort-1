Three independent, flat script files with no imports/exports or build configuration — each file is a self-contained Node.js example: `index.js` shows function declaration and invocation, `condition.js` demonstrates if/else branching on an age parameter, and `Object-Key.js` defines an `isLegal` function that reads nested object properties (`user.address.city`) to decide voting eligibility. There are no shared modules, package manifests, or entry points beyond running each file directly with `node`.
